================================================================================
Примеры curl-запросов к Training Course Tracker
================================================================================
Базовый адрес через балансировщик: http://localhost
Прямой адрес API: http://localhost:8080

--------------------------------------------------------------------------------
1. Проверка работоспособности API
--------------------------------------------------------------------------------
curl http://localhost:8080/health

--------------------------------------------------------------------------------
2. Получить список всех курсов
--------------------------------------------------------------------------------
curl http://localhost:8080/api/courses

--------------------------------------------------------------------------------
3. Получить курс по ID
--------------------------------------------------------------------------------
curl http://localhost:8080/api/courses/1

--------------------------------------------------------------------------------
4. Создать новый курс
--------------------------------------------------------------------------------
curl -X POST http://localhost:8080/api/courses \
  -H 'Content-Type: application/json' \
  -d '{"title":"Основы C# и .NET","description":"Вводный курс",
       "instructor":"Иван Петров","category":"Programming",
       "credits":6,"startDate":"2026-09-01","isActive":true}'

--------------------------------------------------------------------------------
5. Обновить курс
--------------------------------------------------------------------------------
curl -X PUT http://localhost:8080/api/courses/1 \
  -H 'Content-Type: application/json' \
  -d '{"title":"Основы C# и .NET 2","instructor":"Иван Петров","category":"Programming","credits":8}'

--------------------------------------------------------------------------------
6. Удалить курс (каскадно удалятся уроки и записи)
--------------------------------------------------------------------------------
curl -X DELETE http://localhost:8080/api/courses/1

--------------------------------------------------------------------------------
7. Регистрация пользователя (через балансировщик порт 80)
--------------------------------------------------------------------------------
curl -X POST http://localhost/api/auth/register \
  -H 'Content-Type: application/json' \
  -d '{"username":"ivan","password":"secret"}'

--------------------------------------------------------------------------------
8. Вход в систему (получение JWT)
--------------------------------------------------------------------------------
curl -X POST http://localhost/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"ivan","password":"secret"}'

--------------------------------------------------------------------------------
9. Получить данные текущего пользователя (требует JWT в заголовке Authorization)
--------------------------------------------------------------------------------
# Сначала получите токен, затем подставьте его вместо <TOKEN>
curl -H "Authorization: Bearer <TOKEN>" http://localhost/api/auth/me

--------------------------------------------------------------------------------
10. Записать пользователя на курс (через progress-service)
--------------------------------------------------------------------------------
curl -X POST http://localhost/api/progress/enroll \
  -H 'Content-Type: application/json' \
  -H "Authorization: Bearer <TOKEN>" \
  -d '{"userId":1,"courseId":1}'

--------------------------------------------------------------------------------
11. Отметить урок как пройденный
--------------------------------------------------------------------------------
curl -X POST http://localhost/api/progress/lesson \
  -H 'Content-Type: application/json' \
  -H "Authorization: Bearer <TOKEN>" \
  -d '{"userId":1,"courseId":1,"lessonId":1,"completed":true}'

--------------------------------------------------------------------------------
12. Получить прогресс пользователя
--------------------------------------------------------------------------------
curl -H "Authorization: Bearer <TOKEN>" http://localhost/api/progress/1

================================================================================
Минимальный сценарий использования (через балансировщик на порту 80):
================================================================================
# 1. Открыть http://localhost в браузере — откроется веб-интерфейс (web-frontend)
# 2. Зарегистрироваться: POST /api/auth/register
# 3. Войти: POST /api/auth/login -> получить JWT
# 4. Посмотреть курсы: GET /api/courses
# 5. Записаться на курс: POST /api/progress/enroll
# 6. Посмотреть прогресс: GET /api/progress/{userId}

================================================================================
Проверка сохранения данных в PostgreSQL после перезапуска:
================================================================================
# 1. Создать курс (запомнить id)
ID=$(curl -s -X POST http://localhost:8080/api/courses \
  -H 'Content-Type: application/json' \
  -d '{"title":"Проверка сохранности","instructor":"Тест"}' | jq -r .id)

# 2. Перезапустить контейнеры (volume db_data сохраняется)
docker compose down
docker compose up -d

# 3. Убедиться, что данные на месте
curl -s http://localhost:8080/api/courses/$ID | jq
